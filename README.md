# Image Modifier (VB.NET)

A Visual Basic application that converts color images into grayscale using multiple methods.

## Features
- Monochrome threshold
- Gray averaging
- Luma weighting
- Desaturation
- Decomposition (max/min)
- Single-channel (red, green, blue)

## How to Use
1. Click **Open** to load an image.
2. Select a grayscale filter from the dropdown.
3. Click **Convert** to apply it.
4. Click **Save** to store the result.
